# 🌤️ Aether — Realtime Global Weather

A sleek, real-time weather web app built with HTML, CSS, and JavaScript.

## 🌐 Live Demo
[weatherapp-kappa-eight-56.vercel.app](https://weatherapp-kappa-eight-56.vercel.app)

## ✨ Features
- 🔍 Search any city worldwide
- 🌡️ Real-time temperature (°C / °F toggle)
- 🕐 24-hour hourly forecast
- 🌅 Sunrise & Sunset times
- 📍 Popular city quick links
- 🌙 Dark theme UI

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- Weather API

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/kiran99089/Weather_App.git

# Open in browser
open index.html
```
